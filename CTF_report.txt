# CTFとは
CTFとは、サイバーセキュリティの技術を競う大会です。コンピュータを使った知識・技術・発想力を活かして、「flag（フラグ）」 と呼ばれる問題の答えとなる文字列を探し出すことを目指します。CTFは「Capture The Flag」の略で、日本語では「旗取りゲーム」と訳されることもあります。

#CTFで得られること
CTFの問題に取り組むことで、サイバーセキュリティに必要な技術力を実践的に鍛えることができます。また、CTFの競技時間は数時間から数日間に及ぶこともあり、体力や集中力と多角的なアプローチで解決策を導き出す問題解決力も重要になってきます。

#CTFの形式
CTFには主に2つの形式があります。
	-Jeopardy形式（クイズ形式）
	ジャンル別に用意された問題を解いて得点を競う形式です。

	-Attack & Defense形式（攻防戦）
	チームごとにサーバを持ち、他チームからの攻撃を防ぎつつ、相手の脆弱性をついてflagを奪う形式です。

一般的に、CTFの大会の予選ではJeopardy形式、決勝ではより高度な技術とチームワークが必要となるAttack & Defense形式が採用されています。

#Jeopardy形式の問題の分類
Jeopardyの問題の分類は基本的に下記の9種類に分かれています。

| ジャンル | 問題傾向 | 使用知識例 |
|---|---|---|
| Crypto | 暗号を解読する問題 | 暗号化アルゴリズム |
| Web | Web系の脆弱性を突く問題 | HTTP, DB, Webセキュリティ |
| Network | 通信解析などの問題 | TCP/IP, パケット解析 |
| OSINT | 情報収集を行う問題 | 検索力 |
| Forensics | メモリ解析系の問題 | ファイル解析, メモリ解析 |
| Reversing | デバッグ系の問題 | アセンブリ, コーディング |
| Stegano | 画像解析系の問題 | 画像, 音声, 動画解析 |
| Pwn | 不正アクセス系の問題 | デバッグ技術 |
| Misc | その他の問題（謎解き系など） | 幅広い知識 |
